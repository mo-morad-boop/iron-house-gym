# IRON HOUSE GYM — Demo Website

عينة موقع جيم (صفحة واحدة) للعرض على العملاء. مبني بـ Next.js + Tailwind CSS.

## التشغيل محليًا
npm install
npm run dev

## تعديل المحتوى
- الأسعار والروابط والصور والعنوان: `lib/config.js`
- النصوص (عربي / إنجليزي): `lib/translations.js` و `lib/extra.js`
- الصور: `public/images`

## مصادر الصور
صور الجيم والرياضي المستخدمة هنا للعرض التجريبي فقط، وتُستبدل بصور العميل الحقيقية.
